# G25 family calculator

## Family calculator

Open [calculator/index.html](calculator/index.html) in a browser. It works offline and needs no installation. Choose **1 input** to see separate top-10 modern and ancient reference populations and their Euclidean G25 distances for one G25 row, followed by relaxed and strict mixture fits. Or choose **2 parents**, **4 grandparents**, **8 great-grandparents**, or **16 great-great-grandparents** to calculate family coordinates. Use **Choose** to search the bundled reference populations or **Paste** to enter a custom G25 row. Tables scroll horizontally on narrow screens.

In **1 input**, separate unsupervised two-way tables check every modern–modern pair and every ancient–ancient pair. Each pair's nonzero shares are optimized to minimize distance and shown as percentages, with the larger share first. Population names omit redundant category labels in these tables. Each table shows the top 10 by default; a shared slider can show up to 100 per table. The strict two-way table checks every two-slot combination of modern references at exactly 50/50, including the same reference twice. The strict four-way table ranks the true top 100 from all four-slot combinations of modern references at exactly 25% per slot; a reference may occupy multiple slots. Each strict table has its own 10–100 display slider, starting at 10; moving it reveals already-calculated results. The four-way calculation uses a 25-dimensional pair-sum index and a proven distance bound to skip combinations that cannot enter the top 100; the shortlist supplies only an initial bound, not the final results. The analyses run sequentially in a background worker, including when opening the HTML file directly, and a progress bar tracks the exhaustive four-way search. All tables rank by Euclidean G25 distance × 100. The strict tables omit contribution percentages because their shares are fixed. These coordinate fits cannot identify a person's actual ancestors.

Fill every ancestor slot to calculate an offspring average. Its output label joins the ancestor names with `+`. If offspring is also entered, click any person (or use **Compare**) to select a comparison target. Clicking the offspring compares its entered coordinates with the calculated offspring. Clicking an ancestor compares their entered coordinates with the estimate inferred from the offspring and all other ancestors (`N × offspring − sum(other ancestors)` with equal weights, or the corresponding weighted inverse with **Male** enabled). The selected row is highlighted and the output G25 row and all tables update for that person.

In the **2 parents** tab, the **Male** toggle changes the weights from 50%/50% to 51% mother and 49% father. In the **4 grandparents** tab, it changes the weights from 25% each to 25.5% for each maternal grandparent and 24.5% for each paternal grandparent. These weights also apply to residual contributions and missing or selected ancestor estimates. The 8- and 16-ancestor tabs keep equal weights.

The calculator shows up to 10 closest matches for both the entered and calculated selected person, with only that person's genetic distance in each table. These two lists rank all reference populations without a distance cutoff; the opposing target is included when it ranks in a top 10 list. Separate tables rank up to 10 smallest and largest values of AC − BC, AC / BC, and D3 = `(AC − BC) / (AC + BC)` across the selected modern, ancient, or combined reference set. Their shared distance slider starts at 10 and extends to the furthest AC or BC among the selected references; an entry appears only when both AC and BC are at or below the slider value. AC is the entered target's distance to a population; BC is the calculated target's distance. References with BC = 0 are excluded from ratio rankings, and rows with AC + BC = 0 are excluded from D3 rankings.

If offspring is entered and exactly one ancestor is blank, the main output and that ancestor's slot show their **full inferred coordinates**: `(offspring − sum(weight × known ancestor)) / missing ancestor's weight`. With equal weights, this is `N × offspring − sum(known ancestors)`, where `N` is 2, 4, 8, or 16. If several ancestors are blank, the main output is their **combined residual contribution**: `offspring − sum(weight × known ancestor)`. Its label shows that subtraction, such as `Child-0.25*Pop1-0.25*Pop2` or `Child-0.0625*Pop1`. Several missing ancestors cannot be solved individually from these inputs. The inputs for each generation are retained while switching modes; **Clear all** resets them.

These results are coordinate arithmetic, not biological predictions of a specific person's DNA.
